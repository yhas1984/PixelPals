# ASO baseline — 2026-09-20

Measurement source: Google Play Console, last 28 days.

| Metric | Baseline |
| --- | ---: |
| Store listing visitors | 163 |
| Unique install/open clicks | 26 |
| Aggregate click-through rate | 16% |
| Default listing visitors | 159 |
| Default listing conversion | 10.1% |

The first evaluation window is 28 days after the new listing becomes public. The initial target is an aggregate click-through rate of at least 20% without reducing first opens. No final conclusion should be made before the listing reaches 300 visitors.

Store listing experiments remain paused while traffic is insufficient. Start only when the Play Console estimator predicts completion in six weeks or less. Test one asset at a time, beginning with the icon and then the first screenshot, using unique install clicks and the default statistical settings.
