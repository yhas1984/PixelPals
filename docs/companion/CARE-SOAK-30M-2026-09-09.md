# Current 30-minute care soak

Completed on the disposable `FinAI_Test` emulator, serial `emulator-5580`, using the current debug APK identified in `evidence/care-soak-current/run.json`. This APK includes the home pause correction. Its SHA-256 still matched at the end of the run.

## Observed result

- Continuous lab duration: **1,802,527 ms (30 minutes, 2.527 seconds)**.
- Same app PID throughout: **4456**; 46 process/memory observations.
- **388 rounds and 388 completion callbacks**. The captured log contains every round 0–387 exactly once, with callback counter `round + 1`.
- Four complete blocks of 90 unique pet/action pairs: all 15 pets × six care actions, twice in automatic mode and twice with synthetic manual contact. The final 28 rounds begin another automatic block.
- No fatal exception in the captured process log; explicit `SOAK_COMPLETE` matched the reported counters and duration.
- Total PSS: first **44,025 KiB**, minimum **44,025 KiB**, maximum **54,418 KiB**, final **49,454 KiB**. Active atlas allocation reported **6,291,456 bytes**. These are emulator observations, not a battery estimate or proof that every possible leak is absent.

## Evidence and precautions

`final-log.txt` records actual callbacks; `final-coverage.json` verifies contiguous rounds, unique combinations and unchanged APK identity. `soak.json` retains every memory sample, and `monitor-output.txt` captures the completed collector output. The first two blocks were also independently saved during the run.

A fresh app process was launched. Clearing logcat failed, so the lab tag was independently read and confirmed empty before launch. The collector already running in memory used the earlier monitor implementation; it was not restarted while the on-disk parser was hardened. The clean baseline, unchanged PID, contiguous full callback log and explicit closure were checked separately at completion.

## What this gate does and does not prove

This is a prolonged render/controller exercise. The lab directly supplies pointer contact to the controller and counts callbacks; it never writes real rewards or pet progress. Repository reward correctness has separate transactional tests. This run does not prove physical touch delivery, overlay/service lifetime, visual anatomy/frame consistency, battery use, final release signing or real Play purchase/restoration behavior.

The all-15-species **emulator care soak gate is now evidenced**. Physical-device review, prolonged physical performance/compatibility tests, remaining artwork improvements and release/Play checks remain outstanding; the complete project plan is not finished.
