# Diablillo rest handoff

Normal scheduled sleep waits for FLYING with speed at most 1 px/s and an upright
body. Climbing and dashing retain their completion paths. Once flying with rest
requested, autonomous decisions stop and velocity, offsets and rotation decay
exponentially before the shared wing-wrap sleep renderer takes over.

Reduced motion uses RestFadeTransition at the same window position: it resets the
internal flight state, velocities and upright pose only while invisible, then
waits for full opacity before handing off. Canceling or destroying restores
visibility. No permanent desktop object is added.

ImpRestTest covers committed-state readiness, monotonically decreasing velocity,
negative subpixel rounding, cancellation, invisible pose reset and unchanged window
position. These controller checks do not establish visual acceptance of the actual
wing-wrap art or every device's compositor timing. The wider plan remains open.
